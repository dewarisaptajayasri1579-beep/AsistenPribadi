Penjelasan tiap langkah

  1. Kamu kirim chat → request masuk ke POST /api/agent.
  2. Owner vs actor: sistem cek siapa yang login (actor, untuk pencatatan biaya/log) dan siapa pemilik data workspace (owner — semua jadwal/tugas memang punya satu pemilik bersama meski yang login bisa banyak orang).
  3. Waktu sekarang disisipkan ke pesan, bukan ke system prompt — supaya system prompt (aturan asisten) tetap identik setiap request dan Anthropic bisa memakai prompt caching (lebih murah, lebih cepat).
  4. Claude membaca perintah + daftar 9 tools yang tersedia (create_task, create_schedule, check_schedule_conflict, get_today_tasks, dll), lalu memutuskan: ini permintaan bikin jadwal → panggil tool create_schedule dengan parameter yang sudah dia hitung sendiri dari bahasa natural ("besok minggu jam 10" → tanggal+jam absolut Asia/Jakarta).
  5. Tool dieksekusi di server kita (bukan oleh Claude) — create_schedule otomatis cek bentrok jadwal dulu sebelum insert ke database. Kalau bentrok, tidak jadi dibuat dan Claude akan diberi tahu supaya bisa menjelaskan ke kamu.
  6. Dicatat ke AgentRun — jejak audit: siapa yang minta, tool apa yang jalan, hasilnya apa.
  7. Hasil tool dikirim balik ke Claude sebagai tool_result, lalu Claude menyusun kalimat balasan natural dalam Bahasa Indonesia (tanpa menjelaskan proses internal, sesuai aturan di system prompt).
  8. Dicatat ke AiUsageLog — token in/out, model, estimasi biaya Rupiah — inilah yang muncul di menu Biaya AI.
  9. Balasan + label model (Haiku) ditampilkan di chat.

Loop tool-calling ini bisa berulang sampai 6 kali (MAX_TOOL_ITERATIONS) kalau Claude perlu memanggil lebih dari satu tool berturut-turut (misal: cek jadwal dulu, baru buat tugas terkait).
